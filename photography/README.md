## Gallery

Selected photographs will appear here with titles and short captions. Categories will be added when there are enough images to make them useful.

## Adding photographs

1. Start with about 10–20 strong images.
2. Keep originals backed up elsewhere. Put web-sized copies in `photography/images/`.
3. Remove location metadata and check for private details before publishing.
4. Use descriptive filenames, captions, and alternative text.

Photographs remain the photographer’s work. This repository grants no permission to reuse portfolio photographs.
